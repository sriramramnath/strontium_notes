# Visual Differences: Obsidian vs Strontium Notes

## Window & Chrome

1. **Window Controls**: Strontium Notes has macOS traffic lights (red/yellow/green) prominently visible; Obsidian's are less emphasized
2. **Title Bar**: Strontium Notes shows "Strontium Notes" in the title bar; Obsidian doesn't show app name
3. **Window Background**: Strontium Notes has a slightly warmer dark gray; Obsidian is cooler/darker
4. **Top Bar Height**: Strontium Notes has a taller top bar; Obsidian's is more compact

## Navigation & Tabs

5. **Tab System**: Obsidian uses traditional browser-style tabs; Strontium Notes has no visible tabs
6. **Breadcrumbs**: Strontium Notes uses breadcrumb navigation (Markdown > NOTE_NAME); Obsidian shows breadcrumbs below tabs
7. **Tab Close Buttons**: Obsidian has X buttons on tabs; Strontium Notes doesn't have tabs to close
8. **New Tab Button**: Obsidian has a "+" button for new tabs; Strontium Notes doesn't
9. **Active Tab Indicator**: Obsidian highlights active tab with background color; N/A for Strontium Notes
10. **Navigation Arrows**: Both have back/forward arrows but styled differently

## Sidebar

11. **Sidebar Width**: Strontium Notes has a noticeably wider left sidebar
12. **Sidebar Background**: Strontium Notes sidebar is slightly lighter than main area; Obsidian's is darker
13. **File List Density**: Obsidian's file list is more compact; Strontium Notes has more spacing
14. **File Icons**: Different icon styles - Strontium Notes uses document icons; Obsidian uses different iconography
15. **Folder Disclosure**: Both use arrows but different sizes and styles
16. **Sidebar Icons (Top)**: Strontium Notes has larger, more spaced icons; Obsidian's are smaller
17. **Search Icon**: Different positions and styles in each app
18. **Sidebar Divider**: Different visual treatment of the divider between sidebar and content
19. **File Selection**: Different highlight colors for selected files
20. **Folder Indentation**: Strontium Notes has more pronounced indentation

## Typography

21. **Heading Size**: Strontium Notes has significantly larger H1 headings
22. **Heading Weight**: Strontium Notes headings appear bolder
23. **Body Text Size**: Strontium Notes uses larger body text
24. **Line Height**: Strontium Notes has more generous line spacing
25. **Font Family**: Appears to use different default fonts (both sans-serif but different)
26. **Monospace Font**: Code blocks may use different monospace fonts
27. **Heading Spacing**: More space above/below headings in Strontium Notes
28. **List Item Spacing**: Strontium Notes has more vertical space between list items
29. **Bold Text Weight**: Different bold weights in rendered markdown
30. **Text Color**: Slightly different white/off-white for main text

## Editor Area

31. **Content Width**: Strontium Notes content area is wider
32. **Editor Padding**: Strontium Notes has more horizontal padding
33. **Vertical Spacing**: More generous vertical rhythm in Strontium Notes
34. **Emoji Rendering**: Both render emojis but potentially different sizes
35. **Bullet Points**: Different bullet point styles and sizes
36. **Checkbox Rendering**: Different visual treatment of checkboxes (✅ ❌)
37. **Nested Lists**: Different indentation amounts
38. **Horizontal Rules**: Different styling (if present)
39. **Block Quotes**: Different visual treatment (if present)
40. **Code Blocks**: Different background colors and padding

## UI Controls & Buttons

41. **Toolbar Icons**: Different icon sets and styles in top toolbar
42. **Icon Size**: Strontium Notes generally uses larger icons
43. **Button Spacing**: More space between toolbar buttons in Strontium Notes
44. **Hover States**: Likely different hover effects (not visible in static screenshots)
45. **Menu Buttons**: Different three-dot menu styling
46. **Settings Icon**: Different gear/settings icon designs

## Status Bar

47. **Status Bar Height**: Obsidian has a visible status bar at bottom; Strontium Notes' is more subtle
48. **Word Count Display**: Different positioning and styling
49. **Status Bar Background**: Different background colors
50. **Status Bar Text Size**: Obsidian's appears smaller and more compact

## Overall Design Philosophy

- **Obsidian**: Dense, information-rich, traditional desktop app aesthetic
- **Strontium Notes**: Spacious, modern macOS-native feel, minimalist approach
