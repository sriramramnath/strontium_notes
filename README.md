## 🔑 How to Configure AI

1. Click Settings (⚙️) at bottom of Activity Bar
2. Click "AI Assistant" tab in left sidebar
3. Enter your Google Gemini API key
4. Click "Get API Key →" if you need one

---

## 🚀 How to Use

### Open a Vault:
1. Click folder icon at bottom of Activity Bar
2. Select a folder on your computer
3. Start taking notes!

### Create Notes:
- Click "+" in sidebar
- Or press `Cmd+N`

### Use AI Assistant:
- Click sparkles icon (✨) in editor toolbar
- Type your question
- Press Enter

### Command Palette:
- Press `Cmd+Shift+P` or `Cmd+K`
- Use arrow keys to navigate
- Press Enter to execute
